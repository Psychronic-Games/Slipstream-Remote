# YY-Thunks: lets the one Windows build start on Windows 7 SP1 and 8.x.
# Rust's standard library and some dependencies import functions that only
# exist on Windows 8/10 (GetSystemTimePreciseAsFileTime, WaitOnAddress,
# ProcessPrng, ...); Windows refuses to start a program that imports a
# missing function. Linking this object replaces those imports with small
# stubs that call the real function when Windows has it and an equivalent
# fallback when it doesn't. Newer Windows behaves exactly as before.
# MIT licensed: https://github.com/Chuyu-Team/YY-Thunks
# scripts/build-station.sh and the release workflow fetch it, check these
# hashes and hand it to build.rs as SLIPSTREAM_YY_THUNKS;
# scripts/check-windows-imports.py then checks the built executable.
